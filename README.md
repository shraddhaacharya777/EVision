# EVision ⚡

EVision is an EV Charging Station Finder and Booking application.

## Features

- View available charging stations
- Search charging stations
- Filter stations by charger type
- View station details
- Book a charging slot
- View existing bookings
- Update bookings
- Cancel bookings
- Display station availability
- Form validation
- REST API integration

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- REST API
- Postman
